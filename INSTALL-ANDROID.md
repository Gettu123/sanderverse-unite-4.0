# Instalar Sanderverse Unite no Android

1. Baixe [sanderverse-unite.apk](https://github.com/Gettu123/sanderverse-unite-4.0/releases/download/v4.0-android/sanderverse-unite.apk)
2. Abra o download (Arquivos / Chrome)
3. Se aparecer “origem desconhecida”, toque em **Permitir**
4. Instale e abra o app **Sanderverse Unite**

Requisitos: Android 7 ou mais novo. O jogo roda no aparelho, sem Play Store.
