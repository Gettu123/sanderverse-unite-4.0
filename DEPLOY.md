# GitHub Pages — Sanderverse Unite 4.0

1. Crie um repositório (ex.: `sanderverse-unite`).
2. Suba **os arquivos desta pasta** na raiz (index.html visível, não uma pasta dentro da outra).
3. Settings → Pages → Branch `main` → folder `/ (root)` → Save.
4. Espere o check verde e abra o link que o GitHub mostrar.

Se a tela ficar preta: o `index.html` não está na raiz, ou faltou a pasta `assets/`.
Se a música não tocar no iPhone: use o ajuste de volume na tela inicial e toque em Entrar na Arena (o áudio precisa de um toque).

Não precisa de Node, npm, Vercel nem servidor.
