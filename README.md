# Sanderverse Unite 4.0

MOBA HTML5 de 5 minutos. Sem servidor.

- Times: Sander / Cristian / Babalu vs Polo / Lupe / Topete
- Némesis Omega no centro
- Pontue no gol **contrário**
- Especial de Aura Energy (E) recarrega em 50s
- Analógico 360° · D-pad para espiar · Q / W ataques

## Android (APK)

Baixe e instale no celular (Android 7+):

**https://github.com/Gettu123/sanderverse-unite-4.0/releases/download/v4.0-android/sanderverse-unite.apk**

1. Abra o arquivo `.apk`
2. Permita instalar apps desta fonte se o Android pedir
3. Abra **Sanderverse Unite**

Não está na Play Store — instalação direta (sideload).

## Jogar no navegador

Abra o GitHub Pages deste repositório (Settings → Pages, branch `main`, pasta `/root`).

ZIP do site: **https://github.com/Gettu123/sanderverse-unite-4.0/archive/refs/heads/main.zip**
